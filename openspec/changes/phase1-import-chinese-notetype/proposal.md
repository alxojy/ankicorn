## Why
The user must get existing decks onto the phone and review HSK vocabulary with the layout PLAN.md specifies. The demo also needs sample cards.

## What Changes
- Import `.apkg` (`import_anki_package`) and `.colpkg` (`import_collection_package`) from Files and as an "Open in" document type, with progress and a result summary.
- A bundled "Chinese vocab (2-way)" note type with two card templates and Ink-styled CSS, added on first launch if missing.
- `--seed-sample` also adds about 20 invented Chinese notes plus 2 Basic and 2 Cloze notes (idempotent).
